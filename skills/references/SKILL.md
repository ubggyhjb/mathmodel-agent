# 数学建模规范知识库

本知识库文件 `math_modeling_norms.md` 提供长期稳定的数学建模规范和防错知识。

## 使用方法（文件式检索）

1. **按需读小节**：先读 `math_modeling_norms.md` 开头目录表，跳到与当前任务对应的小节。
2. **关键词 grep 检索**：用 grep 工具直接搜关键词（如"TOPSIS""数据泄露""灵敏度""匿名"）定位具体条款。
3. **选型必查**：2analysis-modeling 阶段为每个子问题选定模型前，必须查"模型大分类与选型速查"及对应模型详细指南小节，确认模型适用条件。

## 小节索引

| 小节 | 何时查 |
| --- | --- |
| 赛题理解与子问题识别 | 读题、拆子问题时 |
| 假设与模型建立 | 写模型假设、公式时 |
| 题型防错速查 | 每个子问题选型时 |
| 代码实现与结果 / 编码阶段常见错误 | 3coding-visual 写代码时 |
| 图表与可视化 / 非数据图工具选择 | 3coding-visual、4drawio 画图时 |
| 论文写作 / 论文写作规范补充 | 5writing 写论文时 |
| 论文验收与一致性 | 6verity 验收时 |
| 模型大分类与选型速查 + 各类模型详细指南 | 2analysis-modeling 选型时 |
| 美赛（MCM/ICM）专项规范 | 美赛论文写作时 |

不要把它当作固定产出模板；具体产物仍以当前 skill 和用户要求为准。
